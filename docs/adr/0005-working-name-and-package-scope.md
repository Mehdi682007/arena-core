# ADR-0005: Working Name and Internal Package Scope

Status: Accepted

## Context

The product has no final brand. Internal identifiers must be game-agnostic and must not rely on a publisher trademark.

## Decision

Use `Arena Core` as a temporary working name and `@arena-core/*` as the private package scope.

## Consequences

Names are neutral and consistent across tooling. They are not a public brand commitment and may be replaced through a later, deliberate repository-wide change.
