# FC 26 catalog sources

Checked on 2026-07-25.

## Official EA catalog facts

- EA's release-date page lists exactly seven FC 26 platforms: PlayStation 5, PlayStation 4,
  Xbox Series X|S, Xbox One, Nintendo Switch, Nintendo Switch 2, and PC.
- EA Help groups PlayStation 5, Xbox Series X|S, and PC for cross-play, and separately
  groups PlayStation 4 and Xbox One.
- EA states that Nintendo Switch and Nintendo Switch 2 do not support cross-play. The
  fixture models each as a singleton compatibility pool so every game platform belongs
  to exactly one `CrossplayGroup`.
- EA describes Competitive and Authentic gameplay presets; Competitive is intended for
  head-to-head play.

## Arena Core house rules

The following values are Arena Core product decisions, not claims about EA defaults:

- `pc` is the operational default platform in this seed.
- `1v1` and `2v2` are Arena competition modes.
- Both initial rulesets use Competitive gameplay, six-minute halves, extra time and
  penalties, with custom squads disabled.

Changing a published configuration requires a new ruleset version. The seed deliberately
fails when an existing active version differs from the fixture.
