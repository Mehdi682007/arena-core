# `@arena-core/eslint-config`

ESLint Flat Config presets exported as `base`, `node`, `next`, and `nest`. The `next` preset adds Next.js Core Web Vitals rules; the Nest preset builds on the Node rules without coupling linting to Nest runtime packages.

TypeScript rules use type-aware project service, including unmanaged-promise checks. Prettier compatibility is applied last to prevent formatting-rule conflicts.
